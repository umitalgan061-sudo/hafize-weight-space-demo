⚙️ Weight-Space Harness

Model ağırlıklarını güvenli sandbox'ta düzenleme, değerlendirme ve onay altyapısı

📦 Core Modules

sandbox.py

Tensor okuma/yazma, forward-pass bütçesi, checkpoint diff, safetensors I/O

eval_harness.py

MATH-500, GSM8K, IFEval, Regression benchmarks

reviewer_agent.py

Bağımsız doğrulama: regresyon, risk, istikrar analizi

human_gate.py

İnsan onay kapısı: diff özeti, eval karşılaştırması, karar kaydı

🚀 Demo Simulation

Aşağıdaki butonlar mock bir düzenleme akışını simüle eder. Gerçek entegrasyon için model sağlayıcısından read_tensors, write_tensors, run_forward, run_eval API'leri gerekir.

📋 Architecture

┌─────────────────────────────────────────────────────────────┐
│                    WEIGHT-SPACE HARNESS                      │
├─────────────────────────────────────────────────────────────┤
│  1. PROPOSAL GENERATION                                      │
│     Agent hypothesizes tensor edits → sandbox.write_tensor() │
├─────────────────────────────────────────────────────────────┤
│  2. SANDBOX VALIDATION                                       │
│     budget.forward_pass() → eval_harness.run_full_suite()    │
├─────────────────────────────────────────────────────────────┤
│  3. INDEPENDENT REVIEW                                       │
│     reviewer_agent.review() → risk assessment                │
├─────────────────────────────────────────────────────────────┤
│  4. HUMAN GATE                                               │
│     human_gate.create_request() → human decides              │
├─────────────────────────────────────────────────────────────┤
│  5. DEPLOYMENT                                               │
│     checkpoint.save() → production rollout                   │
└─────────────────────────────────────────────────────────────┘
